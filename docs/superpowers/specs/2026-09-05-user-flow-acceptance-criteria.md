## How to use this document

Each criterion corresponds to exactly one numbered step in the approved user
flow. A status may change to `Complete` only when the expected outcome is
demonstrated by the stated scenario and its evidence is recorded here. Code or
supporting records without the complete user-visible outcome qualify only as
`Partly complete`.
